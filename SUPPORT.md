# Support

GrantTrace is an actively maintained public beta. Support is provided on a
best-effort basis, with no guaranteed response time or service-level agreement.

- For setup and usage help, start with the
  [documentation](https://toxfied.github.io/GrantTrace/docs/) and
  [troubleshooting guide](https://toxfied.github.io/GrantTrace/docs/troubleshooting/).
- For reproducible bugs, product proposals, or catalog gaps, search existing
  [issues](https://github.com/ToxFied/GrantTrace/issues) and use the matching
  [issue template](https://github.com/ToxFied/GrantTrace/issues/new/choose).
- GitHub Discussions are not currently enabled. Use an issue for an actionable
  documentation or product problem, and see [CONTRIBUTING.md](CONTRIBUTING.md)
  before proposing a change.
- Report suspected vulnerabilities privately by following
  [SECURITY.md](SECURITY.md), never through a public issue.
