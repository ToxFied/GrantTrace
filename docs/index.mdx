title: Overview
description: Scenario-bound GitHub App REST permission contracts.
---

GrantTrace turns the REST operations exercised by named, instrumented test
scenarios into a deterministic permission contract you can review in Git.

<Callout type="info" title="Guarantee boundary">
  GrantTrace reports the permissions those scenarios demonstrably require. It
  does not claim whole-application least privilege; untested paths, GraphQL,
  uninstrumented clients, and behavior outside recorded scenarios stay outside
  the result.
</Callout>

## Workflow

```text
instrument scenario → record route evidence → review contract diff
→ commit granttrace.lock.json → check it in CI → optionally prove live
```
